## Determinism (gemma4:26b, sequential, NUM_PARALLEL=1)

Source: `docs/inf/raw/determinism_gemma4_26b*`.
- **T=0 with seed 42:** 3/3 identical on both a planning and an execution prompt. It stayed identical after a model unload/reload. T=0 with no seed was also identical (2/2).
- **T=0.7 with seed 42:** 3/3 identical **within one model load**. **After a reload the output changed** (`060f…` → `971d…`) and then stayed stable (2/2) in the new load.
- **Seed 43 vs seed 42 at T=0.7:** different on the planning prompt, identical on the short execution prompt.

What this means for the design: seeded sampling can give a reproducible factual-vs-sham pair only if all F/S/K arms of a checkpoint run in the same server and model-load session. Record the load session, keep `OLLAMA_KEEP_ALIVE` long, and never reload mid-checkpoint. Keep `common_randomness_claim: none`. **The starter's TogetherClient never sends `seed` (or `reasoning_effort`)**, so only `GuardedChatClient` gives seed control.

## Guard module: `ccc/infra/budget_guard.py`

The guard enforces the following:

**Allowlist**
- Local: `gemma4:26b` and `gemma4:latest`, on loopback http only.
- OpenRouter: `cohere/north-mini-code:free`, on `https://openrouter.ai/api/v1` only.
- Refused:
  - router aliases (`openrouter/*`)
  - non-`:free` models
  - Ollama `*cloud*` models
  - unknown backends

**Per-run call cap** (every retry counts). One call in flight.

**OpenRouter**
- A zero-pricing check is required per run.
- `apply_openrouter_key_status()` sets the daily cap from `/key` as `remaining − reserve`, plus a ledger count of today's attempts.
- The request is sent with `usage.include` and `provider.allow_fallbacks=false`, `max_price=0`, with no `models`, `plugins` or web search.
- It halts on:
  - positive `usage.cost` or positive `cost_details` (a **global** halt)
  - missing cost
  - a resolved-model mismatch
  - HTTP 402/429

**Halts** persist in the ledger until an explicit `halt_cleared` record is written by the owner.

**Modal** is BLOCKED unless `ops/resource_policy.local.json` sets `modal.status` to APPROVED. It also requires:
- a verified billing snapshot no older than 1 h
- a reservation before launch
- a cumulative cap of **$45** (configurable lower, never higher)

Re-recording billing after each job enforces the cap.

**Keys** are read by name only. Local calls get the placeholder `ollama`. The OpenRouter key is never sent anywhere except openrouter.ai.

**Ledger** entries are append-only JSONL with fsync. Lines containing forbidden keys or key-like strings are refused, and error text is scrubbed.

Supporting files:
- `GuardedChatClient` is a drop-in for Terrarium's `TogetherClient` interface. It passes `seed`, `top_p` and `reasoning_effort`, with no hidden retries (TogetherClient's default is 6 silent retries, including on 429).
- `ccc/infra/e2e_colosseum_guarded.py` shows how the runner wires it into the unmodified starter.
- `ccc/infra/tool_loop_bench.py` is the benchmark harness.

Tests: `tests/infra/test_budget_guard.py`, 16 tests, OK under the network-denied sandbox:

## Throughput forecast (gemma4:26b no-think, 1 in flight)

Window: about 2026-10-23 16:50 UTC to 2026-10-25 12:00 UTC, **≈ 43 h**.

Assumptions:
- A branch continuation starts at a checkpoint after planning round 1 and runs the rest of the 4-agent episode: planning round 2 (4 turns × 3 calls) plus execution (4 turns × 1 call). That is **8 agent turns, ≈ 16 calls**.
- Calls take the measured end-to-end mean of 4.0 s/call, so one continuation takes **≈ 64 s, ≈ 56 continuations/h**.
- A full-episode base run is 28 calls, about 113 s.
- 50% duty cycle, because the machine is shared with development and analysis, which gives about 21 compute hours.
- Longer contexts, 6–8 agents or more planning rounds will slow calls; re-measure at freeze.

## Other findings and risks

- The Ollama CLI (`ollama list`) **auto-launched the Ollama desktop app's server** with default settings: cloud enabled, blob pruning on. I stopped it (it was not running before INF-001) and started a controlled server:

  ```
  OLLAMA_HOST=127.0.0.1:11434 OLLAMA_NO_CLOUD=1 OLLAMA_NOPRUNE=1 OLLAMA_NUM_PARALLEL=1 OLLAMA_MAX_LOADED_MODELS=1 OLLAMA_CONTEXT_LENGTH=32768 OLLAMA_KEEP_ALIVE=30m ollama serve
  ```

  Use the HTTP API, not the CLI, to avoid re-launching the app.
- The starter's `TogetherClient` drops `seed`, retries 429s up to 6 times by default, and calls `load_dotenv(override=True)`, which loads the repo `.env` (including `OPENROUTER_MODEL=openrouter/free`). Use `GuardedChatClient`.
- `poseidon-run` falls back to **hosting on Modal** for models that neither Nebius nor OpenRouter serves. Never use `poseidon-run` for CCC runs.
- Server state at handoff: **stopped**. Restart with the command above.
