# SCI-001 Source Ledger

**Owner:** SCI-001 (closest-prior-art and claim review). **Check date:** 2026-10-23.
**Method:** I pulled bibliographic metadata from the arXiv API (`export.arxiv.org/api/query`) by ID: title, full author list, v1 date and latest version. I read passages through arXiv HTML using WebFetch. A bounded child verifier read the Kaur, Tran & Yu, Shi and Cha papers. I checked non-arXiv URLs with HTTP fetches. All of this cost $0.

**Status key**
- **V-meta**: the title, authors and year were confirmed at the primary URL or the arXiv API. Only the abstract was read.
- **V-text**: V-meta, plus specific passages read in the full text (quoted in `novelty_matrix.md` / `claim_review.md`).
- **V-partial**: the source exists, but some metadata or the relevant passage could not be confirmed.
- **UNVERIFIED**: the source could not be confirmed. Do not cite it until it is resolved.

The "First author" column holds the first author, then "et al." when there are more than two authors. Dates are arXiv v1 dates unless noted.
