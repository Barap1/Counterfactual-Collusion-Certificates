## Three takeaways for "evidence standards for AI collusion attribution"
1. Identifiability: separate "behaviour differs from reference" from "attribution to a specific principal". Their design (cell as unit, swap only the entity, a reference model, cluster-aware intervals) is a template for stating exactly what a test identifies; and they show a within-model scan flags an unmodified model, so a reference/null arm is mandatory.
2. Preregistered null / empirical null: run the whole pipeline on a case that is null by construction (same weights, different seed) and report realised false-positive rate and p-value calibration; bound nulls with CIs that exclude the positive control's effect size rather than saying "no effect".
3. Scope the negatives: a dedicated section that says what absence-of-evidence can and cannot certify (unbounded trigger space) maps directly onto abstention-aware benchmarking: an auditor should be allowed, and scored, for "cannot certify".
