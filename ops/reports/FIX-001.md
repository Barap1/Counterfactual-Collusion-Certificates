## Git handoff limitation

The authorized command `git add ccc/fixtures/ tests/fixtures/ docs/fix/ ops/reports/FIX-001.md` failed with actual output:

```text
fatal: Unable to create '/Users/aarav/Documents/Projects/ApartSprint/.git/index.lock': Operation not permitted
```

The lock file does not exist. The session's filesystem policy permits reads of
`.git` but blocks writes, and approval escalation is unavailable. Therefore the
working checkout's branch cannot be updated here. A real local commit is
constructed in an isolated temporary Git object database, using the checkout's
HEAD as parent and explicit `git add` of only the four owned paths.
`docs/fix/FIX-001.bundle` transports that commit;
`docs/fix/COMMIT_HANDOFF.md` records the exact commit and verification commands.
No push, reset or clean is used. The bundle/handoff metadata themselves are
created after the portable commit to avoid a self-referential commit hash.
